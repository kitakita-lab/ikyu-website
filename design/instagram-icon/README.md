### 高解像度化の方法（Version 3）

元のロゴは 559px 幅のため、そのまま拡大すると縁がぼやける。生成 AI のアップスケールやトレース（描き直しに当たる）は使わず、**輪郭の再標本化**を採用した（`mark_alpha_hr`）。

1. 元のアルファを 32bit 浮動小数のまま Lanczos で拡大し、回転する
2. 元の 0.3px 相当のぼかしで、8bit の段差だけを均す
3. 不透明度 50% の等値線（元ロゴの輪郭の位置）を境に、出力 1.5px 幅のなめらかな縁を付け直す

形は元のまま、縁だけが出力解像度でくっきりする。検査（`final/checks.json` の `logo_fidelity`）：

- 面積比（高解像度版／正式ロゴ）0.9994（太りも痩せもない）
- 元の大きさに縮小して正式ロゴと比べた画素の差：平均 0.27%。輪郭の画素だけでは平均 6.6%（縁が鋭くなった分）
- 比較した方式：単純な Lanczos 拡大は縁がぼやける。等値線の前のぼかし 0／0.3／0.5px を比べ、段差が消えて角が丸まらない 0.3px を採用
- 正式ロゴの `k` の上端は画像の端に接しているため、透明の余白を足してから拡大した（端で輪郭が欠けないように）。元画像に 1〜4 程度のごく薄い不要な画素があったが、等値線の外なので出力には出ない

### 角度（Version 2・人間の指示）

正式ロゴは「handmade accessories」と並べる前提で右上がりに傾いている。アイコンではサブテキストを付けないため、水平にする（人間の指示。指示時の見立ては約 3°）。

- 実測：筆跡の主軸（画素の不透明度で重み付けした主成分）は **右上がり 3.71°**。列ごとの筆跡の重心を直線で近似すると 4.8°、下端を結ぶと 5〜6°（手書きのベースラインは揺れるため、全体の向きを表す主軸を採用）
- 回転量 3.7° で主軸は 0.0°。3.0° では 0.7° の右上がりが残る（`preview/compare-angle.png`）

### 視覚的なバランス（Version 3・4 で確認）

- 角度：3.0°／3.7°／4.5° を円形で見比べ、3.7° が水平に見えることを確認した（数値上も主軸 0.01°）
- 左右：ロゴの重心は外接矩形の中心より左にある（`i` `k` `y` が詰まり、右端は小さな `.`）。Version 3（幅 78%）では、右へずらすと `.` が円の縁に近づいて窮屈に見えたため、ずらさなかった。Version 4（幅 60%）では円の縁まで余裕があるため、右へ 0／1／2% と、右 1%・上 1% を比べ、**右へ 1%** を採用した（重心の左寄りが和らぎ、`.` 側の余白も十分。2% では左の余白が目立つ）
- 上下：重心はキャンバス中心より約 1% 上、`y` の払いが下に垂れる。円の中で偏りは見えないため調整なし

## 拡大倍率と画質の制約（事実）

| 要素 | 元 | 4096px での倍率 | 画質 |
| --- | --- | --- | --- |
| 背景 | 1254px | 約 3.27 倍（Lanczos） | ディテールは増えない。等倍で見ると筆跡の細い溝がやや柔らかい。生成 AI の拡大は模様を描き足すため使っていない |
| ロゴ | 559px 幅（筆跡部分） | 約 2.93 倍（輪郭の再標本化。Version 4 の 60% では 4.40 倍、Version 3 の 78% では 5.72 倍） | 縁はくっきり。ただし形の精度は元の 559px の情報が上限で、元の画素より細かい筆跡の揺れは再現できない |

- Instagram のアイコンは最大でも 320px 程度で表示されるため、4096px の大部分は表示時に縮小される（推測）。表示上の画質は背景・ロゴとも十分な見込み
- 印刷など大きく使う場合は、ロゴのベクター版（AI/SVG/PDF）か 4000px 以上の透過 PNG があれば `src/logo-mark.png` を差し替えて `build.py` を再実行すれば作り直せる

## 承認後の検証（Version 4 の縁処理・Version 4 時点）

Version 4 で、倍率 1.5 倍未満のときは縁を付け直さない分岐を加えた。Codex レビューは上限のため未実施（人間が了承）。代わりに次を確認した（2026-11-02、Pillow 12.3.0・numpy 2.5.3）。

- 自動検査：`npm run lint`・`npx tsc --noEmit`・`npm run build` 成功、`build.py` の構文確認 OK
- 完成 PNG：修正後のコードで作り直した 4096px が、コミット済みの完成 PNG（修正前のコードで書き出し）と**全画素一致**（差 0）。完成 PNG は倍率 4.40 倍で、修正した分岐を通らない。PNG・RGB・4096×4096
- 倍率ごとの縁処理（ロゴ幅 180〜3195px の 13 段階）：どの倍率でもロゴの最大不透明度は 100%（修正前は倍率 1.5 倍未満で 95〜98% 止まり）。面積比は 0.997〜1.006 で、分岐の境目（1.499 倍→1.512 倍）でも 1.0005→0.9992 と連続
- 縮小画像：完成 PNG を 1024／320／150／110／77／56px に縮小しても、ロゴの芯は白（RGB 247〜255、最大 255）。44・32px は線が 1px 未満のため芯は無く、最も明るい画素は 254.7・248.3
- 既知の差（修正しない）：`preview/` の 1024px 確認画像は、完成 PNG を縮小したものに比べロゴの位置が約 0.75px（キャンバスの 0.07%）ずれている。原因は、倍率 1.5 倍未満の経路では正式ロゴのごく薄い不要な画素（不透明度 1〜4）が残り、外接矩形がわずかに広がるため。完成 PNG と `final/` のプレビューには影響しない。目視では区別できない
