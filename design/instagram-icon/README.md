# ikyu Instagram プロフィールアイコン

## 目的・成功条件

採用済みの背景画像に、既存の正式ロゴ（`ikyu.` の筆跡部分）を白で中央に置き、Instagram の円形表示・小サイズ表示でも `ikyu` と認識できる正方形アイコンを作る。デザインの採否は人間が判断する。

## 現在地

- 状態：**デザイン承認待ち**（1024px 確認画像と A/B/C 比較を提出済み）
- 次の工程：人間が案（A/B/C）を選ぶ → `python3 build.py final --variant <案>` で 4096px PNG を作り `final/` に追加する
- 未実施：4096px の完成 PNG（承認後に作る）

## 素材と出どころ

| ファイル | 内容 |
| --- | --- |
| `src/background.png` | 採用済みの背景（ChatGPT で生成、1254×1254、無加工のまま保存） |
| `src/logo-mark.png` | 正式ロゴ `public/images/logo.png`（900×166）から「handmade accessories」を除いたもの（559×166、元の濃茶のまま） |

### 正式ロゴを使ったことの確認

- 元データ：`public/images/logo.png`（リポジトリ内で唯一のロゴ。サイトのヘッダー・フッター・構造化データで使用中。SHA-256 は `preview/checks.json`）
- サブテキストの除去は「x ≥ 340 かつ y ≥ 98 の矩形を透明にする」だけ。事前に連結成分を調べ、この矩形には `ikyu.` の筆跡の画素が 1 つも無いことを確認した（`y` の払いは x ≤ 309 で終わる）。
- `build.py preview` が毎回、矩形の外の画素が正式ロゴと完全一致することを検査する（`mark_pixels_identical_to_official_outside_subtext_box: true`）。
- 白ロゴはこのアルファ（形）をそのまま白で塗ったもの。別フォント・描き直し・トレースはしていない。

## レイヤー構成（`build.py`）

下から ① 背景 → ② 陰影（ロゴの形をぼかした濃茶 `#45362F`＝正式ロゴの文字色）→ ③ 白ロゴ。各レイヤーと配置・陰影の値は `build.py` 冒頭の定数で変えられる。

| 項目 | 値 |
| --- | --- |
| ロゴ横幅 | キャンバスの 78% |
| 配置 | ロゴ外接矩形の中心＝キャンバス中心 |
| 円形トリミング | 外接矩形の四隅が内接円の半径の 81% 以内（切れない） |

| 案 | 陰影 | 見え方 |
| --- | --- | --- |
| A | なし | 背景の淡い部分でロゴが溶けやすい |
| B（推奨） | 不透明度 0.28・ぼかし小 | 形の輪郭が出て、陰影自体はほぼ気づかれない |
| C | 不透明度 0.42 | 小サイズで最も読みやすいが、浮き出た印象になる |

## 確認画像（`preview/`）

- `icon-1024-{A,B,C}.png`：1024×1024 の確認画像
- `circle-1024-{A,B,C}.png`：Instagram の円形表示の再現（正方形の内接円で切り抜き）
- `small-{A,B,C}.png`：実寸の円形表示（150 / 110 / 77 / 56 / 44 / 32px、ライト・ダーク画面）
- `compare-ABC.png`：3 案を同じ縮尺で並べた比較
- `checks.json`：機械検査の結果

## 解像度について（事実）

- 背景の元解像度は 1254px。4096px では約 3.3 倍のアップスケールで、ディテールは増えない。
- 正式ロゴの筆跡部分は 559px 幅。4096px ではロゴが約 5.7 倍（1024px でも約 1.4 倍）に拡大される。輪郭は Lanczos 補間のため滑らかだが、拡大した分だけ縁がわずかに甘くなる。
- Instagram はアイコンを最大 320px 程度で表示するため、実用上の影響は小さい見込み（推測）。より大きな用途（印刷等）に使う場合は、ロゴの高解像度・ベクターの元データが必要。

## 再現手順

```sh
pip install pillow numpy
python3 build.py mark      # src/logo-mark.png を作り直す
python3 build.py preview   # preview/ を作り直す
python3 build.py final --variant B   # 承認後
```
