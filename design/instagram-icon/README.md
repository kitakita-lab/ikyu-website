# ikyu Instagram プロフィールアイコン

## 目的・成功条件

採用済みの背景画像に、既存の正式ロゴ（`ikyu.` の筆跡部分）を白で中央に置き、Instagram の円形表示・小サイズ表示でも `ikyu` と認識できる正方形アイコンを作る。デザインの採否は人間が判断する。

## 現在地

- 状態：**最終デザイン承認待ち**（Version 3：4096px の完成 PNG 案 B を `final/` に作成済み）
- 人間が決めたこと（2026-11-02）：陰影は案 B を第一候補／角度 3.7°／ロゴ横幅 78%・中央配置を維持／制作データは承認後に main へ残す
- 次の工程：人間の最終承認 → Draft 解除・マージ（人間）→ Instagram へ設定（人間）

### 正式ロゴを使ったことの確認

- 元データ：`public/images/logo.png`（リポジトリ内で唯一のロゴ。サイトのヘッダー・フッター・構造化データで使用中。SHA-256 は `preview/checks.json`）
- サブテキストの除去は「x ≥ 340 かつ y ≥ 98 の矩形を透明にする」だけ。事前に連結成分を調べ、この矩形には `ikyu.` の筆跡の画素が 1 つも無いことを確認した（`y` の払いは x ≤ 309 で終わる）。
- `build.py preview` が毎回、矩形の外の画素が正式ロゴと完全一致することを検査する（`mark_pixels_identical_to_official_outside_subtext_box: true`）。
- 白ロゴはこのアルファ（形）をそのまま白で塗ったもの。別フォント・描き直し・トレースはしていない。
- 加える変形は拡大と回転だけ（形は変えない）。`src/logo-mark.png` は回転前の正式ロゴの画素のまま保存し、回転は合成時に行う。
- 高解像度版・ベクター版の有無（2026-11-02 再確認）：全 17 ブランチ・全履歴で、ロゴは `public/images/logo.png`（900×166、全ブランチ同一）だけ。`docs/brand-system.md`（別ブランチ）にも「PNG のみ・ベクターはリポジトリにない」とある。

### 高解像度化の方法（Version 3）

元のロゴは 559px 幅のため、そのまま拡大すると縁がぼやける。生成 AI のアップスケールやトレース（描き直しに当たる）は使わず、**輪郭の再標本化**を採用した（`mark_alpha_hr`）。

1. 元のアルファを 32bit 浮動小数のまま Lanczos で拡大し、回転する
2. 元の 0.3px 相当のぼかしで、8bit の段差だけを均す
3. 不透明度 50% の等値線（元ロゴの輪郭の位置）を境に、出力 1.5px 幅のなめらかな縁を付け直す

形は元のまま、縁だけが出力解像度でくっきりする。検査（`final/checks.json` の `logo_fidelity`）：

- 面積比（高解像度版／正式ロゴ）0.9994（太りも痩せもない）
- 元の大きさに縮小して正式ロゴと比べた画素の差：平均 0.27%。輪郭の画素だけでは平均 6.6%（縁が鋭くなった分）
- 比較した方式：単純な Lanczos 拡大は縁がぼやける。等値線の前のぼかし 0／0.3／0.5px を比べ、段差が消えて角が丸まらない 0.3px を採用
- 正式ロゴの `k` の上端は画像の端に接しているため、透明の余白を足してから拡大した（端で輪郭が欠けないように）。元画像に 1〜4 程度のごく薄い不要な画素があったが、等値線の外なので出力には出ない

### 角度（Version 2・人間の指示）

正式ロゴは「handmade accessories」と並べる前提で右上がりに傾いている。アイコンではサブテキストを付けないため、水平にする（人間の指示。指示時の見立ては約 3°）。

- 実測：筆跡の主軸（画素の不透明度で重み付けした主成分）は **右上がり 3.71°**。列ごとの筆跡の重心を直線で近似すると 4.8°、下端を結ぶと 5〜6°（手書きのベースラインは揺れるため、全体の向きを表す主軸を採用）
- 回転量 3.7° で主軸は 0.0°。3.0° では 0.7° の右上がりが残る（`preview/compare-angle.png`）

### 視覚的なバランス（Version 3 で確認）

- 角度：3.0°／3.7°／4.5° を円形で見比べ、3.7° が水平に見えることを確認した（数値上も主軸 0.01°）
- 左右：ロゴの重心は外接矩形の中心より左にある（`i` `k` `y` が詰まり、右端は小さな `.`）。重心に寄せて右へ 1.2%・2.4% ずらす案を円形で比べたが、右へずらすと `.` が円の縁に近づいて窮屈に見えた。両端と円の縁の距離が等しい現在の中央配置（ずらしなし）を維持した
- 上下：重心はキャンバス中心より約 1% 上、`y` の払いが下に垂れる。円の中で偏りは見えないため調整なし

| 案 | 陰影 | 見え方 |
| --- | --- | --- |
| A | なし | 背景の淡い部分でロゴが溶けやすい |
| B（推奨） | 不透明度 0.28・ぼかし小 | 形の輪郭が出て、陰影自体はほぼ気づかれない |
| C | 不透明度 0.42 | 小サイズで最も読みやすいが、浮き出た印象になる |

## 拡大倍率と画質の制約（事実）

| 要素 | 元 | 4096px での倍率 | 画質 |
| --- | --- | --- | --- |
| 背景 | 1254px | 約 3.27 倍（Lanczos） | ディテールは増えない。等倍で見ると筆跡の細い溝がやや柔らかい。生成 AI の拡大は模様を描き足すため使っていない |
| ロゴ | 559px 幅（筆跡部分） | 約 5.72 倍（輪郭の再標本化） | 縁はくっきり。ただし形の精度は元の 559px の情報が上限で、元の画素より細かい筆跡の揺れは再現できない |

- Instagram のアイコンは最大でも 320px 程度で表示されるため、4096px の大部分は表示時に縮小される（推測）。表示上の画質は背景・ロゴとも十分な見込み
- 印刷など大きく使う場合は、ロゴのベクター版（AI/SVG/PDF）か 4000px 以上の透過 PNG があれば `src/logo-mark.png` を差し替えて `build.py` を再実行すれば作り直せる

## main に残す方針

人間の決定（2026-11-02）：承認後、この制作データを main に残す。`design/` はサイトのビルド対象外（`public/` ではない）なので、公開ページには影響しない。完成 PNG（約 18MB）とプレビューで、リポジトリが約 40MB 増える。

## 再現手順

```sh
pip install pillow numpy
python3 build.py mark      # src/logo-mark.png を作り直す
python3 build.py preview   # preview/ を作り直す
python3 build.py final --variant B   # 4096px（約 30 秒）
```
