# ブランド品質の確認 — 機械が見ること・人が見ること

ikyu のサイトは「作品が主役で、静かで、上品」であることが品質そのもの。
ここでは、変更のたびに **機械が自動で確認すること** と、**ブランドオーナー(人)が目で確認すること** を分ける。
美しさ・上品さを点数にはしない。機械が「合格」でも、見た目の判断は人が行う。

ブランドの一次情報は次の3つ。このファイルはそれを言い換えず、確認の観点だけをまとめる。

- 写真:`docs/brand-photo-guidelines.md`
- 色・書体:`src/app/globals.css` の `@theme`(コメントに使い分けの意図がある)
- 言葉:サイトの現行の文章(`src/app/**/page.tsx`・`src/content/*.ts`)

## 1. 機械が確認すること(`npm run verify`・CI の Quality Checks)

| 確認内容 | どこで | 防ぎたいこと |
|---|---|---|
| ESLint・型チェック・静的ビルド | `lint` / `typecheck` / `build` | 壊れたコード、静的書き出しで動かない機能 |
| 曜日と日付の一致(次の出店・イベント実績) | `tests/content.test.mjs` | 「11月23日(月)」のような曜日・祝日表記の誤り |
| 次の出店の ISO 日付と表記の一致 | 同上 | データと画面表示のずれ |
| 写真ファイルの存在・alt・縦横比 | 同上 | 写真の表示切れ・歪み |
| 価格が正の整数、slug の重複なし | 同上 | 作品ページの生成ミス |
| 購入先 URL の形式、仮の値(XXXX 等)の残り | 同上・`scripts/check-site.mjs` | 仮URLのまま本番に出る(過去に実例あり) |
| 文字色×背景色のコントラスト(WCAG AA 4.5:1) | `tests/design-tokens.test.mjs` | 色の調整で文字が読みにくくなる |
| 全ページの title・description・canonical・og:url・og:image | `scripts/check-site.mjs` | 検索・SNS共有の表示崩れ |
| title の重複、h1 が1つ、`lang="ja"` | 同上 | 検索での評価低下・読み上げの混乱 |
| サイト内リンク切れ・ページ内リンク(`#next-event` 等)切れ | 同上 | 押しても飛ばないリンク |
| img の alt、リンクの読み上げ名、外部リンクの `rel="noopener"` | 同上 | 明確なアクセシビリティ違反 |
| sitemap とページの一致、robots.txt、404 の noindex | 同上 | クロール・インデックスの事故 |
| 作品ページに https の購入リンクがある | 同上 | 購入導線の消失(リンク先の妥当性は人が判断) |
| ブランド名の表記(`IKYU`・`Ikyu` を検出) | 同上 | 表記ゆれ |

機械では確認しないこと:外部サイト(minne・Instagram)のリンク先が今も有効か(通信が不安定で誤判定が多いため)。
購入リンクの変更時に人が実際に開いて確かめる。

## 2. 人が確認すること(PR のチェックリスト)

見た目・文章・写真・購入導線に触れる PR では、ブランドオーナーが Cloudflare Pages のプレビューを
**スマホとPCの両方で**開いて確認する。文書・テスト・CI だけの変更なら不要。

### 作品と写真
- 作品が主役になっているか(装飾や文字が作品より目立っていないか)
- 写真が `docs/brand-photo-guidelines.md` に沿っているか(生成り基調・自然光・余白・高彩度の色がない)
- 実際の作品と色・質感・大きさの印象が違わないか(加工しすぎていないか)
- AI 生成・AI 補完の画像が入っていないか
- イベント写真の来場者の顔の処理が外れていないか

### 色・文字組み・余白
- 新しい色や装飾(影・角丸・枠線・グラデーション)が増えていないか。増えた場合は意図が説明されているか
- ゴールド・ロゼなどのアクセントが強すぎないか
- 文字の大きさ・行間・字間が既存ページと揃っているか、日本語の改行が不自然でないか
- 余白が詰まって「量販店のチラシ」のような密度になっていないか

### 言葉
- 「暮らしに花が咲きますように。」の世界観と合っているか(売り込み・煽りの言葉になっていないか)
- ブランド名が小文字の `ikyu`、読みが「イキュ」になっているか
- 価格・日付・会場・数字が事実どおりか(未確定のものを確定と書いていないか)

### スマホ
- 片手でスクロールしたときに自然か、写真が切れていないか、押しにくいボタンがないか
- 下部ナビや花びらの演出が、文字や購入ボタンを邪魔していないか

### 購入導線
- 購入リンクを実際に押して、意図した minne のページが開くか

## 3. 人のチェックが必要かどうかの目安

| 変更したもの | 人のブランド確認 |
|---|---|
| `src/app/`・`src/components/`・`src/app/globals.css` | 必要 |
| `src/content/`(文章・日付・価格・購入先) | 必要(事実の確認が中心) |
| `public/images/` | 必要 |
| `docs/`・`tests/`・`scripts/`・`.github/` だけ | 不要(機械チェックと Codex レビューで足りる) |
