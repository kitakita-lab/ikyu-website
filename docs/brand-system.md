# ブランド情報の共通管理 — サイトと販促物(POP・バナー・SNS画像)の連携設計

状態:設計のみ(2026年10月時点)。新しいリポジトリの作成や他リポジトリの変更はまだ行っていない。

ikyu では今後、サイトのほかにイベント用 A1 POP・大型バナー・卓上POP・休憩中POP・SNS 画像などを AI で制作する。
制作物が増えるほど「色が少しずつ違う」「古いロゴが使われる」「未確定の情報が印刷される」といったずれが起きやすい。
ここでは、サイトと販促物で共通に使うブランド情報と、その置き場所・同期方法を決める。

### 注意

1. **ロゴの印刷用データがリポジトリにない。** 900px 幅の PNG は A1 POP に 40cm 幅で載せると約 57dpi になり、輪郭がにじむ。
   販促物ハーネスを作る前に、ロゴの元データ(ベクター形式の AI/SVG/PDF、または 4000px 以上の透過 PNG)をオーナーから受け取る必要がある。
2. **書体のずれがすでに起きている。** 未マージの営業資料ブランチ(`claude/ikyu-sales-materials-rcn5oy` の `sales/src/style.css`)は、
   サイトの色トークンを手でコピーし、サイトにない Zen Kaku Gothic New を追加している。印刷物の本文にゴシックを使うかは、オーナーが決めて記録する。

## 2. 置き場所の選択肢

| 案 | 内容 | 良い点 | 問題点 |
|---|---|---|---|
| A. サイトのリポジトリを正とする | ブランド情報はこのリポジトリ(`globals.css`・写真ガイドライン・この文書)を正とし、販促物側は写しを持つ | 新しい仕組みが要らない。サイトで実際に使われている値が正になるので古くならない | 販促物側の写しが古くなりうる(同期の確認が要る) |
| B. ブランド専用リポジトリを作る | ロゴ元データ・色・書体・ルールを独立したリポジトリに置き、サイトと販促物の両方が参照する | 制作物が増えても一元管理できる | 今は利用者が1人・制作物が少なく、管理対象が1つ増える。サイト側の書き換え(参照の仕組み)も要る |
| C. 1つのリポジトリにまとめる | サイトと販促物を同じリポジトリに置く(営業資料ブランチの `sales/` 方式) | 同期の問題がない | このリポジトリは**公開**で、`main` への変更は本番に自動デプロイされる。企画書・未許諾の写真・高解像度の元写真・PDF を公開リポジトリに置くことになり、変更のたびにサイトのビルドも走る |
| D. git submodule・npm パッケージで共有 | ブランド情報をパッケージ化して取り込む | 機械的に同期できる | 1人運用には仕組みが重すぎる。AI が扱うときの失敗点が増える |

## 3. 推奨:当面は A、販促物ハーネスは別の非公開リポジトリ

- **ブランド情報の正はこのリポジトリ**(上の表の「一次情報の場所」)。値を変えるときはサイト側を先に変え、PR でブランド確認を受ける。
- **販促物ハーネスは独立した非公開リポジトリ**にする。印刷用の高解像度データ・企画書・利用許諾が未確認の写真を公開リポジトリに置かないため、
  また販促物の更新でサイトのビルド・本番デプロイが走らないようにするため。
- **同期方法**:販促物リポジトリは `brand/` に色・書体・ロゴ・ルールの写しを置き、写した時点のこのリポジトリの commit を記録する。
  制作前に、写しとこのリポジトリの `main`(公開リポジトリなので読み取りに権限は不要)の `globals.css`・ロゴを比べ、違えば止める確認を入れる。
  比べる対象が少ないうちは、この確認だけで十分。
- **案 B へ移る目安**:ブランド情報を書き換える制作物が2つ以上になった、デザイナーなど人が増えた、ロゴ元データなど非公開で版管理したい素材が増えた、のいずれか。
- **営業資料ブランチ(`sales/`)**:このリポジトリにマージせず、販促物リポジトリができたらそちらへ移すことを推奨する(判断はオーナー)。

## 4. 販促物ハーネスに引き継ぐ品質の分け方

サイトと同じく、機械が見ることと人が見ることを分ける(`docs/brand-review.md` と同じ考え方)。

- 機械:仕上がりサイズ・解像度(印刷で 150dpi 以上)・塗り足し・色がトークンの範囲内か・必須表記(ブランド名・日付・会場)の有無・日付と曜日の一致・仮の値の残り
- 人:作品の魅力・余白・文字組み・遠くから見たときの読みやすさ・言葉が世界観に合っているか・実物との印象の差
