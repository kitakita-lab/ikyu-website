## 編集と書き出し

1. 文言は `src/*.html` を直接書き換える。写真は `src/img/` に置いて `src="img/…"` を差し替える
2. `./build.sh` … 確認用 PDF（利用許諾が未確認の写真に「仮配置」表示）
3. `./build.sh final` … 提出用 PDF（「仮配置」表示なし）。**下の確認事項が済んでから使う**

フォントは初回実行時に Google Fonts から `fonts/` へ取得する（Git 管理外）。
